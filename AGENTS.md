# AGENTS.md

## Cursor Cloud specific instructions

This repository (`jinxin-li.github.io`) is a **pre-built static blog** hosted on GitHub Pages. It contains only the compiled HTML/CSS/JS output generated by [Hexo 5.3.0](https://hexo.io/) with the `hexo-theme-matery` theme. There is no source Hexo project, no `package.json`, no build system, and no test framework in this repo.

### Running the site locally

```bash
serve -l 3000 /workspace
```

Or alternatively:

```bash
python3 -m http.server 3000 --directory /workspace
```

The site uses absolute paths (e.g., `/css/...`, `/js/...`), so it **must** be served from the repository root as the web root. Opening `index.html` directly in a browser will not load assets correctly.

### Key facts

- **No lint, test, or build commands exist** — the repo is purely static output.
- **No dependencies to install** — `serve` is installed globally via `npm install -g serve` in the update script.
- Content editing requires the separate Hexo source project (not in this repo). Changes here are typically made by pushing new generated output or editing HTML/CSS/JS directly.
- The blog is in Chinese (zh-CN) and covers Big Data topics (Hadoop, Spark, Flink, Kafka, etc.).
