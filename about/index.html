5. 项目经历
5.1 数据仓库整合建设
  • 构建“数据域 + 业务线”主题化方案，梳理交易域、流量域、用户域、营销域等核心域。
  • 引入大模型代理进行历史模型主题冷启动，历史表主题初始化准确率提升至 80%+。
  • 重设计指标体系与模型流程，支持业务过程多对一映射，降低重复开发。
5.2 基于大模型的 ChatBI 指标问答系统
  • 构建 Java + Python 的问答链路：问题解析、向量检索、Prompt 组装、LLM 回答。
  • 统一沉淀指标与业务知识检索入口，提升内部查询效率与知识复用率。
5.3 用户画像投放系统构建
  • 基于标签 Bitmap 布尔计算实现离线圈选，结合 ClickHouse 承担计算与存储。
  • 覆盖预计算、正式计算、重算、上线/下线、结果推送等全流程能力。
  • 累计支撑 1w+ 人群计算任务，平均耗时控制在 20 秒以内。
5.4 RTA 百亿数据仓库构建
  • 面向日 600 亿级广告数据，采用 Flink + HiveCatalog + 拆队列 + 高并发消费架构。
  • 通过范式建模减少明细层关联与 Shuffle 压力，提升集群稳定性与资源利用率。
  • 日均节约成本约 3000 元。
5.5 行程规划 Agent（新增）
  • 基于大模型 Agent 构建智能行程规划能力，支持多天行程自动生成与动态改写。
  • 综合用户偏好、预算、交通耗时与景点营业时间进行多目标优化。
  • 支持主计划 + 备选方案输出，提升可执行性与用户决策效率。
